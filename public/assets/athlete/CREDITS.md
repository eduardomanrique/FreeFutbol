Sources accessed 2026-09-17:

- Universal Base Characters Standard: https://quaternius.com/packs/universalbasecharacters.html — official free download at https://quaternius.itch.io/universal-base-characters. Superhero_Male_FullBody, Hair_Buzzed, eye and hair textures.
- Universal Animation Library Standard: https://quaternius.com/packs/universalanimationlibrary.html — glTF redistribution of the free Standard library at https://github.com/J-Ponzo/gltf-universal-animation-library (CC0).

The runtime uses retargeted Idle_Loop, Walk_Loop, Jog_Fwd_Loop, Sprint_Loop and Hit_Chest. The football kick is an original authored additive sequence over the retargeted idle pose; it is **not football motion capture**. Runtime clothing colors and shoe shells are generated by CAMPO.

`athlete.gltf` strips the original material maps for runtime kit materials. `Hair_Buzzed.gltf` omits the normal map. `poses.bin` and `motion.json` are generated by `npm run build:motion` from the source animation and character rig. All resources are served locally, with no external download while playing.
